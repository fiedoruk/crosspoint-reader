# Sticky TIMED consumer — device evidence, 12 October 2026

I tested the neutral Sticky binary corresponding to the current TIMED review series. Its SHA-256 is `7d92b33927d8e794225fd92abc2496275b2fc78a7903ac3b0c859187aaaa06c2`. The binary was verified after writing; the partition table was unchanged. No diagnostic handler was added to this candidate and no firmware rebuild was needed.

The test used synthetic 480 × 800, 1-bit BMPs, a local HTTPS endpoint, a dedicated CA and a temporary delivery credential. An existing maintenance image handled SD preparation only; its runtime is excluded from these results.

| Scenario | Observation on the neutral candidate |
|---|---|
| USB-powered refresh | Successive authenticated responses changed the visible image from A to B. A had also been seeded on SD; the transition to B proves a new image reached the panel. |
| HTTP 503 | Five subsequent requests returned 503. The panel retained B and the timer continued to rearm. |
| Untrusted server certificate, USB disconnected | Two TLS connections failed before any HTTP request reached the server. The panel retained B. No client-side TLS error code was captured. |
| Recovery on battery | Restoring the original server certificate without changing reader files produced four authenticated responses and visible B → A → B changes. |
| Return to reading | A public test EPUB was opened and advanced to page 2/6, 4%. After automatic sleep and two successful TIMED deliveries, a physical Power press returned to the same text, chapter, page and progress. |

A separate automated image/OCR check confirmed the visible transitions and reading position. A later SD readback matched B after the USB/battery sequence and A after the book test. These are post-sequence readbacks, not separate file snapshots immediately after every fault. There were 13 authenticated HTTP requests in total: eight successful image responses and five 503 responses.

Missing or disabled configuration, malformed input, storage/commit faults, the low-battery boundary and Power during blocking work retain the existing source/host evidence. This session did not inject each fault on hardware. It does not measure current draw, battery life, the physical low-battery threshold, all reader formats or other models. The reused artwork contains old test labels and dates; it is synthetic content, not live service data.

The test EPUB and device fixture were removed. The saved SD paths matched their original bytes or absence, and the maintenance namespace was cleared. The same neutral binary was written and verified again. After the final write, physical navigation opened Settings. A fresh camera capture and separate OCR check showed Settings / Display and version `1.6.5-dev-detached-fc3aed1`.
